# Terraria Compass

Terraria Compass is a beginner-friendly, Terraria-themed companion site for class
builds across the game's progression.

## Quickstart

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` starts Vite on port 5173.
- `npm run build` creates a production build in `dist/`.
- `npm run lint` runs ESLint.
- `npm run typecheck` runs TypeScript without emitting files.
- `npm run test:ci` runs Vitest once with coverage.
- `npm run test:e2e` runs Playwright specs.
